# B10. Participate in a cybersecurity activity as part of job/internship/volunteering etc.


For this activity, I took part in a cybersecurity-related activity through my part-time work at NPB Security. One of my supervisors, Shaun, told me that his friend had recently experienced a Wi-Fi network breach at home and was trying to find a way to fix it. The person was concerned because the issue involved his personal home network, but the IT technician quotes he was receiving seemed quite expensive for what appeared to be a home-router security problem. When I heard about this, I felt that it was something I already understood well enough to help with, so I volunteered to take a look.

I later went to his home and showed him the possible security problems directly using his own router setup. This made the activity feel very practical and meaningful because it was not just a classroom example or a theoretical problem. It was a real cybersecurity issue affecting someone’s everyday home internet use, and I had the chance to apply my own cybersecurity knowledge in a real environment.

When I checked the router configuration with him, I found three major problems that immediately stood out. First, the router was still using its default administrator login details, which is a serious weakness because default usernames and passwords can often be guessed or found publicly online if they are never changed. Second, the Wi-Fi network was still using the router’s default SSID or network name. This is risky because the network name can sometimes reveal the router brand or model, making it easier for attackers to profile the device and guess possible weaknesses. Third, the router was still relying on older and weaker WPA security settings instead of stronger modern wireless protection. This was important because outdated Wi-Fi protection can make a network easier to attack compared with stronger settings such as WPA2 or WPA3.

After identifying these issues, I explained each problem to him in simple language at his home so that he could understand why they mattered. I did not just change settings silently. I showed him what each setting meant, why the old setup was unsafe, and how a better configuration would reduce the chance of future unauthorised access. I then helped him improve the setup by changing the router administrator password, changing the default Wi-Fi name, and recommending stronger Wi-Fi security settings with a stronger password. I also explained that home-router security is not a one-time task only, because users should continue checking for firmware updates, avoid sharing the Wi-Fi password too casually, and make sure the admin password is not reused elsewhere.

This activity helped me understand that cybersecurity support does not always have to involve a large organisation or complex system. Sometimes a simple home network can still contain serious weaknesses if the router is not configured properly. It also showed me that explaining the issue clearly is just as important as identifying the technical problem, because the person using the system needs to understand what went wrong and how to avoid repeating the same mistake. Overall, this was a useful practical cybersecurity activity because I helped someone improve the security of their home Wi-Fi setup, applied my knowledge in a real situation, and learned how to communicate technical security problems in a simple and helpful way.
